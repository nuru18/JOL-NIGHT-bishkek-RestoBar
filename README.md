# Ночной Бишкек — собранный сайт

Готовая сборка концепт-редизайна сайта рестобара **«Ночной Бишкек»**
(Бишкек, Асанбай Центр, проспект Аалы Токомбаева, 21а/4). Здесь лежит
только результат сборки — исходники в отдельном проекте.

> Концепт-редизайн, неофициально. Данные, фото и видео — из публичной карточки 2ГИС.

## Что внутри

| Раздел | Содержимое |
|---|---|
| Шапка | Живая шкала ночи 18:00 → 06:00 с отметкой «сейчас» |
| 1 + 1 | Отсчёт до конца акции и счётчик стола с экономией |
| Зал | Четыре кадра интерьера и все услуги из карточки |
| Под потолком | Видео зала без звука, рейтинг и вместимость |
| Съёмка | 26 кадров с фильтром по трём режимам света и просмотром во весь экран |
| Бронь | Форма, которая открывает WhatsApp заведения с готовым сообщением |
| Контакты | Адрес, часы, телефон, мессенджеры, оплата |

## Три главные вещи

**Ночь длиной двенадцать часов.** Бар работает 18:00–06:00, а акция «1 + 1»
идёт до полуночи — то есть занимает ровно первую половину ночи. Шкала в шапке
делится пополам и показывает, где вы сейчас.

**Счётчик акции.** В справочнике акция — одна строчка. Здесь видно, сколько
её ещё осталось и во что обойдётся стол. Цену коктейля подставляет гость:
меню заведение нигде не публикует, придумывать его мы не стали.

**Рабочая кнопка брони.** Бэкенда у макета нет, поэтому форма собирает текст
заявки и открывает WhatsApp заведения — номер настоящий, из карточки.

## Про материал

Фото — 26 кадров из альбома заведения в 2ГИС. Съёмка у них идёт в трёх
режимах: тёплое золото, холодный неон и чёрно-белое — фильтр в галерее
разбирает её ровно по этим трём. Кадры с узнаваемыми лицами гостей не брали,
водяные знаки 2ГИС не убирали.

Видео снял гость и выложил в отзывах — так и подписано под роликом.
Единственный ролик от самого заведения — селфи-обращение крупным планом,
зала там почти нет.
